登录 Blackboard

  1. 在浏览器里打开并登录你学校的 Blackboard。
  2. 按 F12 打开开发者工具，切到 Network（网络），再按 F5 刷新。
  3. 在左边 Name 列表里右键一条 me?expand=… 请求，选择 Copy → Copy as cURL (bash)。
  4. 粘贴到下面，点“登录”。

这段内容相当于你的登录凭证，只会发给你电脑上的这个程序，再由它直接连到学校。不要把它发给任何人。
