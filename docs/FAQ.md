# 常见问题（持续更新）

> 这份文档会放进面板的"新手引导"最后，并在面板里随时可以打开查看。

## 双击 start.bat 后提示"端口被占用"或直接打开了网页
说明面板已经在另一个黑色窗口里运行了。直接用打开的网页就行；如果想重启，先关掉所有黑色窗口。

## 点"连接 Blackboard"后没有弹出窗口
- 确认电脑上装有 Microsoft Edge 或 Google Chrome。
- 仍然不行的话，展开页面上的"弹出窗口用不了？改用手动粘贴"，按步骤操作。

## 过一段时间又要重新登录
- 学校登录页如果问"保持登录状态？"，请选"是"。程序靠这个在后台自动续期。
- 面板只有在运行时才会保持登录；关掉黑色窗口后，学校的会话大约 3 小时后过期。下次打开时，一般会自动重新连接。
- 如果学校的单点登录本身也过期了（通常是几周），就需要再点一次"连接 Blackboard"。

## Windows 提示"已保护你的电脑"
点"更多信息"→"仍要运行"。这是因为程序没有付费做数字签名，代码全部公开在 GitHub 上。

## 我的数据安全吗？
程序只在你自己的电脑上运行，只读取、不修改 Blackboard 上的任何内容，也不会把数据发到第三方。登录信息加密保存在你电脑的用户文件夹里。
